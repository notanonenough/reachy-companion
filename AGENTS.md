# Работа агентов в Reachy Companion

Общая ветка разработки — `main`. Перед задачей получи актуальную `origin/main` и прочитай относящиеся к задаче пункты [блокнота решений](docs/REVIEW-NOTES.md).

Готовь изменение в рабочей ветке от этой версии. Для каждого pull request выбирай `main` целевой веткой. При локальном ревью покажи разницу относительно `main` и укажи проверенный коммит. Порядок независимого ревью и приёмки описан в пункте 38 блокнота.

Если за время работы другой агент обновил `main`, проверь совместимость изменений и повтори затронутые проверки. Задача завершена, когда принятые изменения доступны в `origin/main`.
