Независимые авторские read-only проверки после shutdown подтвердили:

- Hub и robot production MainPID0 (failed), camera-sensor MainPID0 (inactive);
- Mac local.reachy jobs отсутствуют, порты18097/18098/18099/8082/8097 закрыты;
- microphone disabled/paused, capture/reader/process закрыты; camera off;
- running move UUIDs пусты. Одна ранняя пара поз немного различалась; поздние
  восемь samples за≈1.2s дали нулевые диапазоны head_pose/head_joints. Это
  ограниченное наблюдение, не доказательство непрерывной неподвижности;

Устойчивый runtime, атрибутированный mic→STT→robot speaker, свежий кадр,
движение+feedback и штатный cleanup **не приняты**. Exit0 stop/shutdown не
заменяет эти gates. Следующий шаг — согласованная с техлидом offline диагностика
задержавшей reducer фазы/стека, независимое ревью/CI, затем новый кандидат и
новое окно ведущего. Новый start без этого не выполняется.
