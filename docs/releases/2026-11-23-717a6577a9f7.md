# RELEASE-01: связанный акустический ответ на кандидате 717

Карточка [#9](https://github.com/notanonenough/reachy-companion/issues/9).
Один ограниченный опыт подтвердил путь **robot microphone → STT → main → TTS →
слышимый правильный ответ**, штатное завершение и отсутствие второго TTS в этом
сеансе. Это протокол кандидата на первый ограниченный стендовый выпуск; решение
о приёмке, теге и GitHub Release принимает ведущий после независимого ревью.
Предыдущие intermittent wrong-answer и reducer-stall этим опытом не объявляются
устранёнными. Длительная автономная работа не проверена.

## Метод одного сеанса

Это существующий normal production Hub в **одном tracked foreground process**
с явным private trace opt-in; параллельный `production-control start` не вызывался.
CLI: `production_start.py hub` с обычными production flags и
`--private-audio-trace ABS_PRIVATE_PATH --private-audio-trace-seconds 150`.
Trace timeout не подменяет runtime lease; следующий start default-off.

## Причинная связь и слышимый результат

Private trace содержит 88 records плюс footer, dropped 0 / incomplete=false,
reason=stop. Все записи используют один trace ID/Hub boot и Hub monotonic basis.
Из 37 STT results один непустой recognized sequence 4 содержит полный смысл
контрольного вопроса и ограничения ответа числом. Имя распознано неточно;
арифметическая задача не потеряна. Exact private source text не публикуется.

Проверены source_boot/sequence/lineage, input_ref/task/attempt, authority и hashes:

- Raw STT, admitted input и actual main request имеют одинаковый text digest.
- Main result — ожидаемое 4, checked=ready; proof/authority согласованы с
  единственным speech_commit и TTS output digest.
- Один TTS stream, complete=true/cancelled=false; 9660 frames submitted, written,
  consumed и stop_consumed. Device provenance=device_consumed_pcm, complete/verified/
  verified_stopped/stop_known=true.
- После него два autonomous main results были discarded, без второго
  speech_commit/TTS. От playback stop до trace end прошло 64.462s.

Владелец независимо подтвердил именно в этом опыте слышимое **«четыре»**.
Вместе с complete causal trace это подтверждает правильный акустический ответ
данного сеанса. Не утверждается отсутствие посторонних звуков вообще.
Независимая Mac запись 76.469s PCM при offline ASR содержит полный контрольный
вопрос, но отдельный robot reply ASR не выделил; PCM/wall alignment не проверен.
Эта запись не выдана за самостоятельное измерение слышимого ответа или его
end-to-end latency. Physical audibility здесь подтверждена владельцем.
